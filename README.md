# Resume Showcase Pro

Build a modern, professional, and highly interactive personal portfolio website
strictly based on my resume.

GOAL:
Create a recruiter-ready portfolio that looks premium, smooth, and engaging
while keeping all content honest and resume-accurate.

INPUT:
I will provide my resume. Use it as the single source of truth.

WEBSITE STRUCTURE:
1. Hero Section
   - My name and professional title
   - Short impactful tagline derived from my resume
   - Smooth animated text reveal
   - Call-to-action buttons (View Projects, Download Resume)

2. About Me
   - Concise, story-driven summary
   - Professional tone, confident wording
   - No fake experience

3. Skills
   - Categorized technical skills
   - Animated skill cards or progress indicators
   - Subtle hover and glow effects

4. Projects
   - Resume-based projects only
   - Clean project cards with hover animations
   - Tech stack, short description, and outcomes
   - Optional modal or expand view

5. Experience & Education
   - Timeline layout
   - Smooth scroll-in animations

6. Contact
   - Contact form with validation
   - Email, LinkedIn, GitHub links
   - Simple and clean layout

DESIGN & UI REQUIREMENTS:
- Dark theme (modern and professional)
- Smooth scrolling and section reveal animations
- Micro-interactions on hover and click
- Clean typography and spacing
- Glassmorphism or soft gradient accents
- Fully responsive (mobile, tablet, desktop)

ANIMATIONS & EFFECTS:
- Fade, slide, and scale animations on scroll
- Hover lift and glow effects on cards
- Smooth button transitions
- Subtle animated background (non-distracting)

CONTENT RULES:
- Improve wording for clarity and professionalism
- Do not invent experience or skills
- Keep everything aligned with my resume

OUTPUT EXPECTATION:
- Complete, ready-to-use portfolio website
- Clean layout and modern UI
- Easy to edit content later
- Suitable for internships and job applications

```sh
git clone <this-repository-url>
cd <repository-name>

```
